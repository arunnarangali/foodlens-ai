# Submission links and checklist

Fill in the trainer's Excel sheet with actual links. Do not use placeholder links as submissions.

| Deliverable | Required value | Current status |
|---|---|---|
| GitHub repository | `https://github.com/<user>/foodlens-ai` after publishing | Pending |
| README | Repository README URL | Draft in scaffold |
| Architecture docs | `docs/architecture.md` URL | Draft in scaffold |
| Prompt history | `docs/prompt-history.md` URL | Template ready; actual usage pending |
| Context management | `docs/context-management.md` URL | Draft |
| Presentation | Real PPT/PDF/Slides share URL | Generated PowerPoint / Google Slides deck at `docs/FoodLens-AI-Presentation.pptx` (upload to Google Slides) |
| Demo | Live URL or recording share URL | Not available |
| Latest commit | GitHub commit URL/SHA | Pending |
| Test evidence | CI URL or sanitized test output | Not run |
| Wednesday Excel sheet | Trainer-provided file/location | Pending |

## Suggested Excel columns
`Session Date`, `Session Topic`, `Project Name`, `GitHub URL`, `README URL`, `Presentation URL`, `Demo URL`, `Latest Commit`, `Test Status`, `Key Learning`, `Next Week Plan`.

Before submission, verify sharing permissions from a signed-out/incognito browser where possible. Never put an API key in the spreadsheet.
